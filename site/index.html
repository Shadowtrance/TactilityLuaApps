Lua apps for Tactility

The Lua runtime, the Lua Apps manager and packaged Lua scripts, served as a Tactility app repository.

Add this repository

  1. Open Software on the device and choose App repositories.
  2. Add the address below and enable it.
  3. Open App Hub. Its apps appear next to the official catalog.
  4. Install Lua Runtime first; packaged Lua apps need it.
