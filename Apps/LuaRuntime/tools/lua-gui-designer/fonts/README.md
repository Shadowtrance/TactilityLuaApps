# Bundled fonts

The designer measures and previews text with the firmware's own fonts. These two
files are the firmware's pre-built subsets, copied from its
`Data/system/fonts/` directory, so the tool works with only the apps repository
and the SDK — no Tactility source checkout needed.

| File | Origin | Licence |
|---|---|---|
| `AdwaitaSans.ttf` | Firmware text subset of Adwaita Sans (derived from Inter, weight 550). Generated by `Tactility/Fonts/generate.py`. | SIL Open Font License 1.1 — see `OFL.txt` |
| `MaterialSymbolsRounded.ttf` | Firmware icon subset of Material Symbols Rounded. Copyright 2026 Google LLC. | Apache License 2.0 — see `LICENSE-Apache-2.0.md` |

They are the exact files the firmware embeds, so a preview at a given font size
matches the device.

## Refreshing

Copy both TTFs from the firmware's `Data/system/fonts/` directory (keep the
licences with them). If a local Tactility checkout is present, the designer
prefers it over these copies; `TACTILITY_FONT` and `TACTILITY_ICON_FONT` point
at another font file and override both.
